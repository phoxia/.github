## What we build

Tools that run lean, stay honest, and give back to the people who use them.

Rust + Axum backends. SvelteKit frontends. PostgreSQL 16. Deployed with Dokploy + Traefik.

## Principles

- **AGPLv3 always** — read the code, verify the behavior, fork if we disappear.
- **Transparent by default** — revenue, costs, and distributions are public at [phoxia.org/transparency](https://phoxia.org/transparency).
- **Single-VPS friendly** — each binary runs at 10–30 MB RAM. No Kubernetes required.
- **Privacy by architecture** — we don't collect what we don't need. Data boundaries are enforced in code, not policy.
- **Reproducible builds** — releases include SHA256 hashes you can verify yourself.
